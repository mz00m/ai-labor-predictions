# Technology & Engineering — AI Tools

## GitHub Copilot

- **Function**: technology
- **Also useful for**: education
- **Pricing**: Freemium ($10/mo for Individual)
- **URL**: https://github.com/features/copilot
- **Verified**: 2026-04-03
- **Confidence**: high

> AI pair programmer that suggests code completions, generates functions, and explains code inline in your IDE.

**Best for:** Software developers at all levels. Auto-completes code, generates boilerplate, writes tests, and explains unfamiliar code. Works in VS Code, JetBrains, Neovim, and more.

**Limitations:** Can suggest insecure or incorrect code. Doesn't understand full project architecture. Works best for common patterns, less reliable for novel or domain-specific logic.

## Cursor

- **Function**: technology
- **Pricing**: Freemium ($20/mo for Pro)
- **URL**: https://cursor.sh
- **Verified**: 2026-04-03
- **Confidence**: high

> AI-native code editor (VS Code fork) with inline code generation, multi-file editing, and codebase-aware chat.

**Best for:** Software developers of all levels. Write code from natural language descriptions, refactor across files, debug with AI assistance. Understands your full codebase context.

**Limitations:** Subscription cost on top of existing tools. Can suggest incorrect code that compiles but has logic errors. Heavy reliance can slow down learning for junior developers.

## Dbt (with AI)

- **Function**: technology
- **Also useful for**: finance, operations
- **Pricing**: Freemium (Cloud from $100/mo)
- **URL**: https://www.getdbt.com
- **Verified**: 2026-04-03
- **Confidence**: medium

> Data transformation tool with AI-powered SQL generation, documentation, and lineage tracking.

**Best for:** Data engineers and analytics engineers. AI generates SQL transformations from natural language, auto-documents models, and explains complex queries. Version-controlled data pipelines.

**Limitations:** Steep learning curve for non-SQL users. Cloud pricing can escalate with usage. Requires existing data warehouse infrastructure.

## Elicit

- **Function**: technology
- **Also useful for**: education, finance, legal
- **Pricing**: Freemium ($10/mo for Plus)
- **URL**: https://elicit.com
- **Verified**: 2026-04-03
- **Confidence**: high

> AI research assistant for finding, reading, and synthesizing academic papers.

**Best for:** Researchers, analysts, and anyone who needs to synthesize academic literature. Searches across 200M+ papers, extracts key findings, identifies methodology, and creates structured summaries.

**Limitations:** Academic papers only (not industry reports, news, etc.). Extraction accuracy varies with paper complexity. Best for English-language research.
