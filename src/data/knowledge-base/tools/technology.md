# Technology & Engineering — AI Tools

## GitHub Copilot

- **Function**: technology
- **Also useful for**: education
- **Pricing**: Freemium ($10/mo for Pro; $39 Pro+, $100 Max)
- **URL**: https://github.com/features/copilot
- **Verified**: 2026-08-27
- **Confidence**: high

> AI pair programmer that suggests code completions, generates functions, and explains code inline in your IDE.

**Best for:** Software developers at all levels. Auto-completes code, generates boilerplate, writes tests, and explains unfamiliar code. Works in VS Code, JetBrains, Neovim, and more. The free tier covers 2,000 completions per month, which is enough to evaluate it before paying.

**Limitations:** Can suggest insecure or incorrect code. Works best for common patterns, less reliable for novel or domain-specific logic. Pricing is now partly consumption-based: completions are unlimited on paid plans, but chat, agent, and code-review work draw down a monthly AI credit allowance ($15 on Pro at 1 credit = $0.01), so heavy agent use costs more than the headline price.

## Cursor

- **Function**: technology
- **Pricing**: Freemium ($20/mo for Pro; $40/user/mo Teams)
- **URL**: https://cursor.com
- **Verified**: 2026-08-27
- **Confidence**: high

> AI-native code editor (VS Code fork) with inline code generation, multi-file editing, and codebase-aware chat.

**Best for:** Software developers of all levels. Write code from natural language descriptions, refactor across files, debug with AI assistance. Understands your full codebase context. The free Hobby tier allows limited agent requests, enough to test the workflow.

**Limitations:** Can suggest incorrect code that compiles but has logic errors. Heavy reliance can slow down learning for junior developers. Every plan now includes only a set amount of model usage; past that, on-demand usage is billed in arrears, so a heavy month can cost well above the $20 base. Higher individual tiers (Pro+, Ultra) exist mainly to raise those agent limits.

## Dbt (with AI)

- **Function**: technology
- **Also useful for**: finance, operations
- **Pricing**: Freemium (Developer free; Starter $100/user/mo plus usage)
- **URL**: https://www.getdbt.com
- **Verified**: 2026-08-27
- **Confidence**: high

> Data transformation tool with AI-powered SQL generation, documentation, and lineage tracking.

**Best for:** Data engineers and analytics engineers. AI generates SQL transformations from natural language, auto-documents models, and explains complex queries. Version-controlled data pipelines. The free Developer tier covers one seat, one project, and 3,000 successful model builds per month, which is workable for a solo analyst.

**Limitations:** Steep learning curve for non-SQL users. Requires existing data warehouse infrastructure. Billing is a hybrid of per-seat and consumption: Starter caps at 15,000 successful model builds per month before overages, dbt State is metered at $0.094 per billable daily active target table, and the dbt Wizard AI features run on a separate credit allowance. Budget from build volume, not seat count.

## Elicit

- **Function**: technology
- **Also useful for**: education, finance, legal
- **Pricing**: Freemium ($49/user/mo for Pro; $169 Scale)
- **URL**: https://elicit.com
- **Verified**: 2026-08-27
- **Confidence**: high

> AI research assistant for finding, reading, and synthesizing academic papers.

**Best for:** Researchers, analysts, and anyone who needs to synthesize academic literature. Searches across 138M+ papers, extracts key findings, identifies methodology, and creates structured summaries. The free tier gives unlimited search, summaries, and chat-with-paper, with capped Research Agent and Research Report runs.

**Limitations:** Academic papers only (not industry reports, news, etc.). Extraction accuracy varies with paper complexity. Best for English-language research. The former $10/mo Plus tier is gone — the entry paid plan is now $49/user/mo, a significant step up for individual researchers, and systematic literature review sits behind it.
