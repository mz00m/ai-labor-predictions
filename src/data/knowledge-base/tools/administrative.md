# Administrative & Office Support — AI Tools

## ChatGPT

- **Function**: administrative
- **Also useful for**: marketing, sales, finance, communications, technology, education
- **Pricing**: Freemium ($20/mo for Plus)
- **URL**: https://chat.openai.com
- **Verified**: 2026-04-03
- **Confidence**: high

> General-purpose AI assistant for text processing, summarization, data extraction, and Q&A.

**Best for:** Ad-hoc information lookup, document summarization, data extraction from unstructured text. Works across virtually all knowledge work tasks.

**Limitations:** No persistent memory across sessions (without custom GPTs). Can hallucinate facts. Not suitable for tasks requiring real-time data without plugins.

## Microsoft Copilot (M365)

- **Function**: administrative
- **Also useful for**: communications, finance, operations
- **Pricing**: Paid ($30/user/mo on top of M365)
- **URL**: https://www.microsoft.com/en-us/microsoft-copilot
- **Verified**: 2026-04-03
- **Confidence**: high

> AI assistant embedded in Word, Excel, PowerPoint, Outlook, and Teams.

**Best for:** Workers already in the Microsoft ecosystem. Automates document drafting, email triage, meeting summaries, Excel formula generation, and PowerPoint creation from within the tools people already use.

**Limitations:** Requires M365 E3/E5 subscription plus Copilot add-on. Quality varies by application (strong in Word/Outlook, weaker in Excel for complex analysis). Enterprise rollout requires admin configuration.
